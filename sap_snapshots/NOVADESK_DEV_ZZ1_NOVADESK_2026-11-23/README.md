# NovaDesk SAP-Quellsicherung

ADT-MCP-Rückgaben aus dem zuletzt rein lesend inventarisierten Stand in NOVADESK_DEV, Paket ZZ1_NOVADESK. Enthalten sind 39 vollständig gelesene aktive Dateien einschließlich beider Behavior Pools mit Includes sowie der Paket-, Typ- und Berechtigungsmetadaten. Zwei Sprachdateien sind laut SAP leer. Hinzu kommt der separat gelesene Veröffentlichungsstatus des OData-V4-UI-Bindings. SHA256SUMS schützt die gespeicherten UTF-8-Dateien.

Die Sicherung dokumentiert aktive Quellen. Sie enthält keine Tabelleninhalte, offenen Draft-Datensätze, inaktiven Editorstände, effektiven Rollenzuweisungen oder Zugangsdaten. Die sechs STOB-Entitäten werden über ihre DDLS-Quellen abgedeckt. Für SCO2 meldet MCP fehlende AFF-Unterstützung. Die Ablage ist eine Quellsicherung und keine geprüfte abapGit-Serialisierung oder Wiederherstellung von Geschäftsdaten.
